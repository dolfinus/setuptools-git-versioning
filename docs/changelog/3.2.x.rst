3.2.x
=====

3.2.2 (2026-11-13)
-------------------

Bug Fixes
~~~~~~~~~

Fixed ``{timestamp}``, ``{timestamp:}`` and ``{timestamp:%s}`` substitutions failing on Windows. (:github:pull:`169`)

``%s`` can be not supported by ``strftime`` on some platforms, including Windows, raising ``ValueError: Invalid format string``.
Now the unix timestamp is computed directly as ``datetime.timestamp()``.

Thanks to :github:user:`TohruSu`.

3.2.1 (2026-11-11)
-------------------

Features
~~~~~~~~

Declare Python 3.15 support.

Bug Fixes
~~~~~~~~~

Fixed version detection from ``.git_archival.txt`` when the archived commit is on a tag like ``2024-01-15``. (:github:pull:`168`)

The tag was parsed as ``2024`` plus one commit, giving ``2024.post1+git.<sha>`` instead of ``2024.1.15``.
Thanks to :github:user:`TohruSu`.


3.2.0 (2026-10-05)
-------------------

Features
~~~~~~~~

- Added support for ``dynamic-metadata`` 0.4+ through the ``setuptools_git_versioning.dynamic_metadata`` provider. (:github:pull:`161`)

  This enables automatic versioning with scikit-build-core 1.0+ and other compatible backends.
  Thanks to :github:user:`ktbarrett`.

- Added new ``prefer_tag: bool = False`` option for :ref:`version-file-option`. (:github:pull:`162`)

  Thanks to :github:user:`lxcxjxhx`.

Deprecation
~~~~~~~~~~~

- Deprecated the ``setuptools_git_versioning.scikit_metadata`` provider. (:github:pull:`161`)

  Migrate to ``[[tool.dynamic-metadata]]`` with ``provider = "setuptools_git_versioning.dynamic_metadata"`` on scikit-build-core 1.0+ or another compatible backend.
